# Palatinus-Barbearia
Desenvolvimento do Projeto - Barbearia Palatinus
Para que o aplicativo funcione devidamente é necessário que o usuário instale em seu dispositivo android (Android 7 ou superior)
É necessário a conexão constade de internet para seu uso (wifi ou dados móveis)
A aplicação se encontra em desenvolvimento, é esperado encontrar erros durante o uso.
